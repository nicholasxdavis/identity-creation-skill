# Blacnova wobnimo fork

This tree is the **Blacnova** copy of wobnimo. It is not kept in sync with npm.

## Do

- Edit engine / CLI / skill here
- Build with `npm install` then `npm run build -w wobnimo`
- Link apps with `npm install file:…/packages/wobnimo`

## Do not

- `npm install wobnimo@latest` over this fork
- `npx wobnimo skill` (disabled; skill lives at `skills/wobnimo-mascot/`)
- Publish this package to the public registry

## Marketing embed checklist

Transparent canvas, `framing` ≥ 1.35, soft `floor`, no opaque white plate behind the host.
