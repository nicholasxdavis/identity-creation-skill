# Identity Creation Skill

Create product identity assets: mascots (Wobnimo or IP logo), transparent favicons, and 1200x630 Open Graph social cards. One skill for brand face, browser mark, and link preview[cite: 1].

## Overview

This skill focuses on identity deliverables only. Pick the lane you need (mascot, favicon, OG) or run a full kit in that order. It does not redesign the whole UI (use `picasso-ui`) and does not score Lighthouse (use `playhouse-audit`)[cite: 1].

## Installation

Add this skill folder to your agent configuration directory or reference it directly in your workspace instructions.

## When to Use

* Building a product mascot, brand character, or IP mark
* Shipping favicons, apple-touch icons, or tab marks
* Creating OG / Twitter link preview artwork
* Assembling a small identity kit before launch
